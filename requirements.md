build an application that interact with a buyer-seller scenario. We have developed a simulated supplier that sells goods through a catalogue and provides an interface for transactions. Each participant (buyer) must create an application to fulfill natural language text orders based on a budget assigned to their bank account. The participant must first build a web-based application to view the catalogue and allow human users to select items to fulfill orders. Participants will then add a natural language agent that can automatically search and fulfill orders. Finally, they will integrate more advanced agentic capabilities using Open Claw. Through the exercise, participants will gain an understanding of different application architectures (from MVC to agents) using different integration methods (MCP vs APIs). The exercise will allow participants with zero prior coding experience to build a fully functional application, while more advanced participants can challenge themselves with more advanced features.

The application encompasses features across 3 levels of difficulty (+1 stretch level):

#### Level 1

- Possess a business domain-specific entity model (class diagram, data model).
- Web user interface.
- User login.
- Ability to save data in a database.
- Has workflow and some internal controller logic.
- Generate some reports.
- Local development version is accessible via the internet.

#### Level 2

- Calling external APIs to:
    - Sending an email
    - Creating a calendar invite
    - Transcribing audio
    - Calling a LLM to perform text generation and summarisation
    - Basic LLM Context engineering
- Receiving webhooks

#### Level 3: Creating an Agent and connecting to external services.

- Open Claw integration
- Vector RAG to build a product Q&A bot
- OCR capabilities

#### Level 4 (Advanced Competency)

- Vector RAG
- Build a product Q&A bot
